GoJames WebApp

การตั้งค่าอีเมลและลิงก์รีเซ็ตรหัสผ่าน

1) คัดลอกไฟล์ .env.example เป็น .env
2) แก้ค่าในไฟล์ .env

EMAIL_SENDER=อีเมลที่ใช้ส่ง
EMAIL_PASSWORD=App Password ของ Gmail แบบไม่มีช่องว่าง
BASE_URL=ลิงก์ฐานของเว็บ

ตัวอย่างตอนทดสอบในเครื่องเดียว:
BASE_URL=http://127.0.0.1:5000

ตัวอย่างตอนทดสอบจากมือถือในวงแลน:
BASE_URL=http://192.168.1.103:5000

ตัวอย่างตอนเอาขึ้น Render:
BASE_URL=https://ชื่อเว็บของคุณ.onrender.com

ติดตั้งแพ็กเกจ:
pip install -r requirements.txt

รันเว็บ:
python app.py

ถ้าจะกดลิงก์รีเซ็ตรหัสผ่านจากมือถือ ต้องใช้ BASE_URL เป็น IP เครื่องคอม หรือโดเมนจริง
ไม่ควรใช้ 127.0.0.1 เพราะมือถือจะมองเป็นเครื่องของตัวเอง

อัปเดตเพิ่มเติมในเวอร์ชันนี้:
- คง UI เดิมจากไฟล์ gojamesstay-master.zip
- แก้ลิงก์กู้รหัสผ่านให้ใช้ APP_BASE_URL / BASE_URL บน Render แทน 127.0.0.1
- เพิ่มสถานะ checked_in = เข้าพักแล้ว
- แอดมินกดปุ่ม "เข้าพักแล้ว" ได้เอง เมื่อถึงวันและเวลาเข้าพักแล้ว
- ระบบแจ้งเตือนลูกค้าเมื่อแอดมินเปลี่ยนเป็นสถานะเข้าพักแล้ว
