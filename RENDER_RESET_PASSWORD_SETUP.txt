วิธีเปิดใช้งานระบบลืมรหัสผ่านบน Render

ระบบลืมรหัสผ่านมีหน้า /forgot-password และ /reset-password/<token> แล้ว
แต่ต้องตั้งค่าอีเมลใน Render ก่อน จึงจะส่งลิงก์รีเซ็ตรหัสผ่านได้จริง

1) สร้าง Gmail App Password
- เปิดบัญชี Gmail ที่จะใช้ส่งอีเมล
- เปิด 2-Step Verification ก่อน
- เข้า Google Account > Security > App passwords
- สร้าง App password สำหรับ Mail
- คัดลอกรหัส 16 ตัวที่ได้ ห้ามใช้รหัสผ่าน Gmail ปกติ

2) ตั้งค่า Environment Variables ใน Render
เข้า Render > เลือก Web Service > Environment แล้วเพิ่มค่าเหล่านี้

EMAIL_SENDER=อีเมล Gmail ที่ใช้ส่ง เช่น gojames.booking@gmail.com
EMAIL_PASSWORD=App Password 16 ตัวจาก Gmail แบบไม่มีช่องว่าง
ADMIN_EMAIL=อีเมลผู้ดูแลระบบที่จะรับแจ้งเตือน เช่น gojames.booking@gmail.com
APP_BASE_URL=https://ชื่อเว็บของคุณ.onrender.com
SECRET_KEY=ใส่ข้อความสุ่มยาว ๆ เช่น gojames-reset-secret-2026
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=465

3) กด Save Changes แล้ว Deploy ใหม่
- Render จะ Redeploy อัตโนมัติ
- ถ้าไม่ขึ้น ให้กด Manual Deploy > Deploy latest commit

4) ทดสอบ
- เข้า /login
- กด ลืมรหัสผ่าน?
- กรอกอีเมลบัญชีที่สมัครไว้ในระบบ
- ตรวจสอบอีเมล แล้วกดลิงก์เพื่อตั้งรหัสผ่านใหม่

หมายเหตุ
- อย่าใส่ EMAIL_PASSWORD ลงใน GitHub หรือไฟล์ .env ที่เป็น Public
- ให้ใส่รหัสผ่านอีเมลเฉพาะใน Render Environment Variables เท่านั้น
